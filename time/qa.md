## O que deve fazer ##

Escrever e executar os testes unitários e de integração para todos os projetos desenvolvidos para validar o funcionamento do ecossistema.
Criar nas camadas Backend e Frontend os testes unitarios e de integração.
Instalar complementos necessarios para a tarefa.
Manter os testes na mesma camada que o teste foi feito.
Criar os mocks para que tenha a maior cobertura possivel.
Teste usando a prática de Testes Parametrizados
Deve cobrir no minimo 80% do codigo

## o que não deve fazer ##

Não deve corrigir o codigo testado, deve encaminhar para o Analista.
