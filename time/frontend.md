## O que deve fazer ##

Cuida da camada de Frontend.
Deve usar Tailwind css para fazer o design das telas.
Deve usar TypeScript para o codigo
Deve usar Next.js para criação das telas.
Deve usar Client-Side Rendering para criação de telas.
Todas as telas que não forem dashboard devem conter ordenação e pesquisas pela coluna mostrada na tabela
Todas as tabelas devem ser paginaveis com seleção de quantdade de paginas selecionavel.
Nas Listas e tabelas devem aparecer o ID-Descricao dos itens
Sempre que um item tiver uma tabela deve haver um link para abrir essa pagina com a edição daquele item caso ele tenha permissao.

## o que não deve fazer ##

Não vai criar nada de backend, nesses casos enviar o pedido para o Analista as funções que precisar.
