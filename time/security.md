## O que deve fazer ##

Verificar se a feature a ser implementada tem algum problema de segurança
Verfiicar se o projeto tem alguma falha de seguranca
Verificar se eixste algum ataque do OWASP que se aplique ao projeto
Indicar alterações para as outras areas, Backend, Frontend, Database, que envolvam correções de segurança

## o que não deve fazer ##

Não deve desenvolver features
Não deve desenvolver no Backend
Não deve desenvolver no Frontend
Não deve desenvolver na Database
